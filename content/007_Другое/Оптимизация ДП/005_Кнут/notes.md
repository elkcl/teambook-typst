# Оптимизация Кнута — Яо

Источник: https://peltorator.org/posts/knuth_yao_optimization/

Рассмотрим динамику по отрезкам:

$$
\operatorname{dp}[l][r]
 = \min_{l \le k < r}
   \left(\operatorname{dp}[l][k] + \operatorname{dp}[k + 1][r] + w(l, r)\right).
$$

Здесь `w(l, r)` не зависит от `k`, а `opt[l][r]` — первое `k`, на котором достигается минимум.

## Точное условие

В общем виде оптимизация корректна тогда и только тогда, когда точка разреза монотонна по обеим координатам:

$$
opt[k - 1][n] \le opt[k][n] \le opt[k][n + 1].
$$

Для интервальной записи это обычно формулируют как:

$$
opt[l][r - 1] \le opt[l][r] \le opt[l + 1][r].
$$

Удобное достаточное условие на функцию стоимости — для `a <= b <= c <= d` функция `w` должна удовлетворять:

1. **монотонности:**
   $$w(b, c) \le w(a, d);$$
2. **неравенству четырёхугольника (условию Кнута):**
   $$w(a, c) + w(b, d) \le w(a, d) + w(b, c).$$

Тогда выполняется нужная монотонность оптимумов:

$$
\operatorname{opt}[l][r - 1]
\le \operatorname{opt}[l][r]
\le \operatorname{opt}[l + 1][r].
$$

Это позволяет искать `k` не на всём отрезке `[l, r)`, а только в пределах:

$$
[\operatorname{opt}[l][r - 1],\operatorname{opt}[l + 1][r]].
$$

Важно доказать условия для конкретной задачи: сама форма динамики ещё не делает оптимизацию корректной.

## Порядок вычисления

Сначала считаются отрезки длины `1`, затем длина увеличивается. Для вычисления `dp[l][r]` уже известны значения `dp[l][k]` и `dp[k + 1][r]`, а также необходимые границы оптимума.

Индексы в коде нужно согласовать с выбранным соглашением о полуинтервалах и базовыми состояниями. В частности, границы `opt` должны быть инициализированы для отрезков минимальной длины.

## Сложность

Без оптимизации перебор всех `k` занимает `O(n^3)`. Благодаря монотонности оптимумов суммарное число проверяемых кандидатов — `O(n^2)`, поэтому время работы `O(n^2)`, память `O(n^2)`.
