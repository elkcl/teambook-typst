# Team Reference

Справочник собирается скриптом `./build`. Он читает `config.json`, находит файлы в `content/` и компилирует `main.typ` в PDF.

Нужны `typst`, `jq` и `find`. Для режима `tour` ещё `clang-format`: им код временно сжимается под узкую колонку. Исходники в репозитории при этом не меняются.

## Сборка

Из корня репозитория:

```bash
./build config.json
```

Режим берётся из поля `mode` в конфиге. Сейчас там `tour`, поэтому команда выше пишет компактный справочник в `notebook.pdf`.

Явно:

```bash
./build config.json tour
./build config.json book
```

Аргумент режима перекрывает `mode` в конфиге.

| Режим | Куда пишет | Что получается |
| --- | --- | --- |
| `tour` | `output_file`, сейчас `notebook.pdf` | Альбомный A4, три колонки. C++ прогоняется через `.clang-format.tour` (ширина 50, без пустых строк). Заметки печатаются только у разделов без кода. |
| `book` | `book_output_file`, сейчас `book.pdf` | Портретный A4, одна колонка. Код как в репозитории (`.clang-format`, ширина 80). Над кодом печатается непустой `notes.md`. Каждый алгоритм начинается с новой страницы, заголовок раздела остаётся на странице его первого алгоритма. |

Имена выходных файлов и режим по умолчанию задаются в `config.json`: `mode`, `output_file`, `book_output_file`. Туда же вынесены название, команда, вуз, состав и дата на титуле.

## Как лежит материал

```
content/preamble.hpp
content/<раздел>/<алгоритм>/code.hpp
content/<раздел>/<алгоритм>/notes.md
```

`preamble.hpp` — общие алиасы, макросы и константы. У алгоритма файл кода называется `code` с исходным расширением (`.hpp`, `.cpp`, `.py`, `.txt`). Заголовок в PDF берётся из имени папки, в нём можно писать разметку Typst. Формульный раздел может состоять из одного `notes.md`.

Порядок разделов в PDF — это порядок, в котором `find` обходит `content/`, без дополнительной сортировки.
